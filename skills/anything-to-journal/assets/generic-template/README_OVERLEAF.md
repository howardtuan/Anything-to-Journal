# Edit this journal project in Overleaf

1. In Overleaf, choose **New Project > Upload Project**.
2. Upload `overleaf-upload.zip` (or select all files from `overleaf-upload/`).
3. Confirm that `main.tex` is the project's **Main document**.
4. Open **Menu > Settings > Compiler** and select **XeLaTeX**.
5. Edit `main.tex`, `references.bib`, the other `.tex` files, figures, and data files as needed, then click **Recompile**.

The ZIP is intentionally flat: `main.tex` is at its root, with no enclosing folder. Keep filenames unchanged unless you also update their `\\input`, `\\includegraphics`, or bibliography references.
